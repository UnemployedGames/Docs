# Normas generales

A continuación se presenta una lista de recomendaciones generales útiles
para cualquier lenguaje o herramienta:

- Mantener el código en inglés, comentarios e indicaciones hacia otros desarrolladores
  en castellano. Téngase en cuenta las siguientes excepciones:
    - GitHub Actions: Aunque el `name` de un `step` esta destinado para indicar al
      desarrollador en la interfaz web el progreso del `workflow`, la gran mayoría
      de `steps` de terceros (incluidos los de la propia GitHub) se encuentran en inglés.
      
      Si no se escriben estrictamente en inglés se llega a una mezcla castellano-ingles
      en la interfaz de usuario incomoda de leer.
